Feasibility first

A candidate is a loop-free path through the illustrative airport graph. Each leg must be within the selected aircraft's nominal range; shipment mass and volume must fit that aircraft on every leg; supported cargo classes and the entered maximum transit time are enforced. Up to four legs are considered.

Mathematical Formulation & Objective Function

For each enumerated, feasible path, the engine applies a min-max normalized weighted-sum scalarization (a multi-attribute utility score):

\[\min_{p \in \mathcal{P}} J(p) = w_{\text{cost}} \cdot \hat{C}(p) + w_{\text{time}} \cdot \hat{T}(p) + w_{\text{co2}} \cdot \hat{E}(p) + w_{\text{sla}} \cdot \hat{R}(p)\]

Variables and parameters

\(\mathcal{P}\)
Finite set of loop-free, feasible physical routes from origin \(O\) to destination \(D\), including direct paths and hub-and-spoke multi-leg paths. A path must satisfy aircraft leg-range, payload, cargo-handling and hard maximum-transit constraints.
\(p, O, D\)
One candidate route, its selected origin airport, and its selected destination airport, respectively.
\(C(p), \hat{C}(p)\)
Total modeled Direct Operating Cost for path \(p\) and its dimensionless min-max normalized value. DOC here combines block-hour operating cost, payload-dependent fuel cost, overflight fees, and landing/handling fees. The abbreviated requested accounting identity is \(\text{Fuel Cost}+\text{Landing/Handling Fees}+\text{Overflight Fees}\); the implemented estimate also includes a base block-hour component.
\(T(p), \hat{T}(p)\)
Total estimated transit duration and its normalized value: great-circle distance divided by the aircraft's nominal cruise velocity \(V\), plus 0.75 h per flight leg for block/turnaround allowance, 2 h per intermediate hub, and 1.5 h at each endpoint.
\(E(p), \hat{E}(p)\)
Shipment-level estimated CO₂ mass and its normalized value. Fuel burn is payload-sensitive and emissions are estimated using 3.16 kg CO₂ per kg of fuel.
\(R(p), \hat{R}(p)\)
Deterministic SLA-exposure proxy and its normalized value. The prototype computes \(R(p)=T(p)/T_{\text{SLA}}+0.10\,N_{\text{transfers}}(p)\), where \(T_{\text{SLA}}\) is the hard maximum transit time and \(N_{\text{transfers}}\) is the number of intermediate hubs. Lower values indicate more remaining SLA buffer and fewer transfer points; this is not an empirical delay probability or a quoted penalty fee.
\(w_{\text{cost}}, w_{\text{time}}, w_{\text{co2}}, w_{\text{sla}}\)
Nonnegative user priorities from the four sliders. If raw slider settings are \(s_k\), each weight is \(w_k=s_k/\sum_j s_j\); when all sliders are zero, the engine uses equal 25% weights. Therefore \(\sum_k w_k=1\).
\(C_{\min}, C_{\max}\), etc.
Minimum and maximum observed values of the named metric across the current feasible candidate set \(\mathcal{P}\); the same definition applies to \(T\), \(E\) and \(R\).

Min-max normalization

\[\hat{C}(p) = \frac{C(p)-C_{\min}}{C_{\max}-C_{\min}}, \quad \hat{T}(p) = \frac{T(p)-T_{\min}}{T_{\max}-T_{\min}}\]
\[\hat{E}(p) = \frac{E(p)-E_{\min}}{E_{\max}-E_{\min}}, \quad \hat{R}(p) = \frac{R(p)-R_{\min}}{R_{\max}-R_{\min}}\]

Each normalized metric lies in \([0,1]\) when its range is nonzero; a constant metric maps to zero. The engine ranks paths in ascending \(J(p)\), then uses cost as a deterministic tie-breaker. Pareto status considers cost, time, emissions, and SLA exposure before the displayed list is limited to the top 40.

Engine Disclaimers & Assumptions

  • Min-Max Normalization Scope: Each of \(C,T,E,R\) is normalized across the currently feasible candidate set \(\mathcal{P}\) for the selected origin-destination pair. If all paths have an identical value for a metric (for example, \(E_{\max}=E_{\min}\)), its normalized value is set to 0 to avoid division by zero.
  • Slider Weight Normalization: Raw slider values are scaled dynamically so the four weights sum to exactly 1.0 (100%); if all sliders are zero, equal weights are used.
  • Heuristic Ranking Scope: The engine enumerates and ranks paths with a multi-attribute utility heuristic on this illustrative airline-network graph. It is a route-choice and feasibility heuristic, not a global fleet-wide integer-programming schedule generator.
  • SLA risk limitation: No observed reliability, delay-probability or contract-penalty data is available here; \(R(p)\) is only a deterministic time-buffer/transfer-count proxy, and the SLA limit itself remains a hard feasibility filter.

Direct Operating Cost (DOC) calculation

DOC ≈ block hours × base block-hour rate + fuel × fuel price + overflight fees + landing / handling fees Fuel burn F (kg/km) is approximated per kilometre as F = a + b · W, where W is shipment payload mass in tonnes, a is the empty-burn term, and b is the payload-sensitive burn coefficient. Base block-hour, fuel price, overflight and airport fee values are synthetic class-level estimates, not airline tariffs or live fee schedules.

Transit time calculation

Transit ≈ great-circle distance / cruise velocity V + 0.75 h × flight legs + 2 h × intermediate hubs + 1.5 h × endpoints Cruise time uses great-circle distance and the selected aircraft's nominal cruise velocity; the 45-minute per-leg allowance approximates turnaround and ground handling, while each intermediate hub receives an additional two-hour transfer buffer.

Planning assumptions

Airport pairs and operating assumptions are synthetic demonstration data, not live schedules or quotes.
Great-circle distance is calculated between airport coordinates; estimated flight time uses nominal aircraft cruise speed.
DOC combines modeled block-hour, payload-sensitive fuel, per-distance overflight, and per-leg landing/handling components.
Fuel burn is payload-sensitive; CO₂ uses an illustrative factor of 3.16 kg per kg of fuel.
Transfer handling adds two hours at each intermediate airport and 1.5 hours at each endpoint.
Capacity represents nominal aircraft payload and hold-volume limits; no load sharing, belly-space inventory or backhaul is modeled.
Special cargo availability is a simplified airport certification flag; real dangerous-goods and temperature-control rules vary.
Taxes, ground transport, weather, curfews, uplift constraints, service reliability and emissions lifecycle effects are excluded.
